## 3个月工作计划

| 任务 | 描述 | 计划 |
| :--- | :--- | :--- |
| **1. 调研与概要设计** | 完成现状调研和概要设计，明确整体架构、接口规范、数据模型和核心流程，为后续开发提供基础 | 第1周 |
| **2. 文档预处理：解析器开发** | 开发文档解析器，支持PDF/Word/Markdown三种格式，自动识别文档结构（标题层级、章节） | 第2周 |
| **3. 文档预处理：切块与入库** | 实现智能切块，建立父子块关联并注入元数据；替换Dify默认切块方式，从源头提升检索质量；完成三库写入 | 第3-4周 |
| **4. 全局字典与路由** | 用MD文件维护关键词到知识库的映射，用户提问时自动路由到对应知识库；引导用户准确表达问题 | 第5周 |
| **5. 问题处理：意图识别、拆解与改写** | 理解用户真实需求：识别问题领域与类型、拆解复杂问题、扩展同义词，提升后续检索的准确性 | 第6-7周 |
| **6. 召回策略：混合检索 + 标签筛选 + 投研融合 + MCP** | 多路召回（语义+关键词）合并最优结果，返回完整上下文；支持标签筛选；打通知识库与投研数据库，统一返回检索结果，并附带文档来源等信息 | 第8-11周 |
| **7. 排序加权：多维度综合排序** | 对召回结果综合排序：相关性、来源权威性、时效性，并根据用户角色微调权重，实现个性化排序 | 第12周 |
| **8. 文档版本管理与整体联调** | 文档变更时自动提醒，人工确认后重新索引；串联全链路，修复集成问题，确保服务可运行 | 第13周 |

## 后续展望

在上述3个月计划完成后，后续将重点推进以下工作：

- **多步规划（ReAct模式 + 复杂任务自主评估）** ：复杂问题自动拆解为多步检索，每一步根据前一步的结果动态调整策略；对检索结果进行置信度评估，信息不足时主动反问、矛盾时说明冲突、严重不足时拒绝回答，让系统具备复杂分析和自主判断能力
- **召回测评**：联合业务专家构建覆盖各知识库的黄金问答对，建立评测流水线，持续追踪召回率、排序质量等核心指标
- **端到端反馈闭环**：提供点赞/点踩和备注功能，建立“反馈采集→问题归类→根因分析→策略优化”的闭环机制，驱动系统持续迭代
